    사용 가이드

    마음에 드는 것만 설치하면, 그다음부터는 평소처럼 Claude에게 말하면 알아서 쓰여요.

    두 가지 방법으로 도구를 챙겨요

    메뉴기준언제
    💬 상담지금 하려는 작업새 작업을 시작하기 전에 "뭐 챙기면 돼?"라고 물어볼 때. 이미 있는 도구도 알려 줘요
    🏢 아침 점검최근 30일 내 사용 이력매일 아침 8시 자동 실행 → 디스코드로 브리핑. 사무실에서 지금 실행도 가능

    하루 루틴

    1. 아침 8시 디스코드 브리핑 확인
    2. 새 작업을 시작할 때는 상담에서 하려는 일을 물어보기
    3. 추천 카드의 자세히 보기로 무엇을 하는지·누가 만들었는지 확인
    4. 설치 명령 복사 → 터미널에 붙여 넣기 → 새 대화(세션) 열기
    5. 평소처럼 작업. 카드의 "이렇게 말하면 돼요" 문장을 그대로 써도 돼요

    설치 방법

    종류방법
    스킬터미널(Git Bash)에서 npx skills add … 실행 → 설치 위치를 물으면 Claude Code 선택 → 새 대화
    플러그인터미널에서 claude 실행 → /plugin install … 입력 → 새 대화

    ⚠️ 공식 표시가 없는 도구는 설치 전에 저장소를 꼭 확인하세요. 검증팀이 방치·소규모 저장소에는 '확인 필요'를 붙여요.

    부서가 하는 일

    부서하는 일
    상담팀질문을 받아 하려는 작업을 파악하고, 결과를 준비물 체크리스트로 설명 (Gemini, 없으면 단어 매칭)
    수집기공식 마켓·Anthropic 스킬·skills.sh 후보와 내 도구 목록을 모음
    점검팀작업과 겹치는 정도로 후보 순위를 매김
    검증팀GitHub 저장소 상태로 통과·경고·탈락 판정, 모자라면 점검팀에 재검토 요청
    브리핑팀아침 점검 결과를 디스코드로 보냄
