📖 skill-scout 사용 가이드

매일 아침 내 작업에 맞는 스킬·플러그인을 골라 알려 줘요. 마음에 드는 것만 설치하면, 그다음부터는 평소처럼 Claude에게 말하면 알아서 쓰여요.

하루 루틴

  1. 아침 8시 디스코드 브리핑 확인 (자동 발송)
  2. 관심 가는 추천은 카드의 자세히 보기로 무엇을 하는지·누가 만들었는지 확인
  3. 설치 명령 복사 → 터미널에 붙여 넣기 → 새 대화(세션) 열기
  4. 평소처럼 작업. 카드의 "이렇게 말하면 돼요" 문장을 그대로 써도 돼요
  5. 설치한 것은 다음 날부터 추천에서 자동으로 빠져요 (🧰 내 도구에서 확인)

설치 방법

종류방법
스킬터미널(Git Bash)에서 npx skills add … 실행 → 설치 위치를 물으면 Claude Code 선택 → 새 대화
플러그인터미널에서 claude 실행 → /plugin install … 입력 → 새 대화

⚠️ 공식 표시가 없는 도구는 설치 전에 저장소를 꼭 확인하세요. 검증팀이 방치·소규모 저장소에는 '확인 필요'를 붙여요.

추천 등급 보는 법

필수내 작업에 거의 매일 도움 — 바로 설치 추천
추천자주 쓸 만함 — 시간 날 때 설치
필요할 때특정 작업(영상, 특정 서비스)할 때만 설치
겹침이미 있는 기능과 겹침 — 안 해도 됨

앞으로 편해지는 점

지금까지앞으로
좋은 도구가 있는지도 모르고 매번 처음부터 시킴아침마다 내 작업에 맞는 것만 골라서 알려 줌
300개 넘는 플러그인 중 뭘 쓸지 직접 찾아봄검증팀이 방치되거나 사용자가 적은 것을 걸러 줌
앱을 만들고 직접 눌러 보며 확인Claude가 브라우저로 직접 테스트하고 스크린샷까지 (webapp-testing)
키 노출 같은 실수를 나중에 발견코드를 고치는 그 순간 경고 (security-guidance)
새 도구가 나와도 모름새로 나온 것 중 내 작업과 관련된 것만 따로 알림
